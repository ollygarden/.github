## Explore the garden

| Project | What it helps you do |
| --- | --- |
| [**OpenTelemetry Agent Skills**](https://github.com/ollygarden/opentelemetry-agent-skills) | Give coding agents current, vendor-neutral OpenTelemetry knowledge grounded in upstream sources. |

| [**Tulip**](https://github.com/ollygarden/tulip) | Run a curated, vendor-agnostic OpenTelemetry Collector distribution with commercial support and long-term maintenance. |
| [**Grafts**](https://github.com/ollygarden/grafts) | Build with custom Collector components, including NATS JetStream and SNMP integrations. |

## How the pieces fit

Our agent skills help you design, implement, and improve OpenTelemetry in your
software. Tulip gives you a supported Collector distribution for running those
telemetry pipelines, while Grafts supplies components that extend what the
Collector can do.

The OpenTelemetry Agent Skills stay vendor neutral and source grounded.
OllyGarden Skills build on that foundation with the practices and workflows we
use in the field.
