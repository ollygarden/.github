# Governance

OllyGarden's open source projects are sponsored and maintained by
[OllyGarden](https://ollygarden.com/). Anyone may propose and contribute changes through public
issues and pull requests.

## Roles

- **Contributors** report problems, propose improvements, author changes, review work, and help
  other users.
- **Maintainers and code owners** review changes, operate project infrastructure, manage releases,
  and help enforce project scope and community policies.
- **Project lead**: OllyGarden's CEO is the sole governance authority for OllyGarden's open source
  projects.

Maintenance and code ownership are operational responsibilities; they do not grant governance
authority.

## Decision making

Maintainers seek consensus through public issues and pull requests whenever practical. The project
lead has final authority over project scope, governance, maintainer and code owner appointments,
releases, and disputes that cannot be settled by consensus.

Governance decisions that materially affect contributors will be documented publicly. Reports
under the [Code of Conduct](CODE_OF_CONDUCT.md) and undisclosed security vulnerabilities may remain
private to protect the people or systems involved.

## Changes to governance

Anyone may propose a governance change through a pull request to this repository. Governance
changes require approval from the project lead.
